### 2.2 Arsitektur Aplikasi
* **Backend & API:** RESTful API yang membaca basis data PostgreSQL `classicmodels`.
* **Frontend:** Web UI interaktif dan responsif (React / HTML5 + Chart.js / Tailwind).
* **Database:** PostgreSQL (menggunakan skema resmi dari `Axon sales - Mysql Database.sql`).
* **Packaging:** Multi-container orchestration menggunakan **Docker & Docker Compose**.
